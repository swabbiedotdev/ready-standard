# Ready standard

The `.ready` standard writes a product's intent as a **Ready Intent Package
(RIP)**, or ready package: a `product/` directory of typed YAML records. The
product is organized into capabilities, outcomes some actor gets. Each
capability draws its behavior as flows (journeys for people, lifecycles for
records) whose edges name the trigger that takes them and the sequence they
run, plus the rules used only there. Data, interfaces, actors, systems, and
anything several capabilities use are shared and defined once. Records link
to each other by id, so the package is a graph that software can check and
render: Ready Room draws every flow, sequence, and data diagram from the
records, and its validator checks every reference.

This repository describes Ready standard 8 (schema `ready: 2`).

```yaml
# product/capabilities/notes/flows/write/compose.ready
ready: 2
kind: step
id: notes.write.compose
capability: notes
flow: notes.write
title: Write and save a note
step_kind: screen
interface: interface.editor
edges:
  - to: notes.write.saved
    trigger: notes.save-note
    sequence: notes.save
    outcome: saved
  - to: notes.write.too-long
    trigger: notes.save-note
    sequence: notes.save
    outcome: refused
```

This repository is the home of the standard as [Ready Room](https://readyroom.dev)
uses it, and of the `ready-standard` agent skill for writing and maintaining
`.ready` packages.

## Using a package

A repository with a ready package keeps it at `product/`, starting with
`product/product.ready`. Validate and export it with the `@readyroom/ready`
package (Node 24+; version 1.0 reads standard 8):

```sh
npx @readyroom/ready validate <repo>          # must report 0 errors
npx @readyroom/ready export <repo> <out>      # readable Markdown book with diagrams
npx @readyroom/ready export <repo> <out>.json --format json
npx @readyroom/ready schema                   # the JSON Schema for one record
```

`<repo>` is the directory that contains `product/`.

To start a package, copy
[skills/ready-standard/assets/template-package/product/](skills/ready-standard/assets/template-package/product/)
into the repository, rename the example capability (`notes`), and replace the
values. Each template's comments list its kind's required and optional fields.
For editor completion, point your YAML language server at
`skills/ready-standard/assets/ready.schema.json` for `*.ready` files.

## Installing the skill

The skill is a standard Claude Code skill folder. Copy or link
`skills/ready-standard/` to `~/.claude/skills/ready-standard/` (personal) or
`<repo>/.claude/skills/ready-standard/` (one project).

## Checking this repository

```sh
scripts/check.sh <ready-room-checkout>
```

It validates the template package (0 errors and 0 warnings required) and
confirms `skills/ready-standard/assets/ready.schema.json` matches the schema
Ready Room generates. See [AGENTS.md](AGENTS.md) for the
full sync procedure.
